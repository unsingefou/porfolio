# Portfolio

A simple, fast, hand-crafted portfolio site built with React, TypeScript, and Vite.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

This site is automatically deployed to GitHub Pages via GitHub Actions whenever you push to `main`.

## Tech Stack

- React + Vite
- TypeScript
- React Router
- Plain CSS
- GitHub Pages
